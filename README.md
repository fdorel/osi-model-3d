# OSI Model 3D Interactive Visualization

A professional-grade React application visualizing the 7-layer OSI model with real-time 3D graphics.

## Tech Stack

| Technology | Purpose |
|------------|---------|
| **React 18** | UI framework (hooks, components) |
| **Vite** | Build tool & dev server |
| **Tailwind CSS** | Utility-first styling |
| **Three.js r128+** | 3D rendering engine |
| **@react-three/fiber** | React renderer for Three.js |
| **@react-three/drei** | R3F helpers (Stars, Environment, etc.) |
| **GSAP 3.12** | Complex timeline animations |
| **Zustand** | Lightweight state management |

## Quick Start (localhost)

```bash
# Clone or copy the project
cd osi-model-3d

# Install dependencies
npm install

# Start development server
npm run dev

# Open browser to http://localhost:3000
